# lab-test-management-across-commercial

A React 18 + TypeScript + Tailwind CSS v4 admin UI, generated by the **UISenz**
LangGraph agent from a backend entity/field specification.

## Design

Clean, trustworthy healthcare payer portal -- teal accent on a neutral, high-contrast, accessible structure.

- Brand color: `#008c86` (see `--color-brand-*` in `src/index.css`)
- Fonts: Helvetica (headings) / Helvetica (body)
- Chosen by: default theme

## Getting started

```bash
npm install
npm run dev
```

The app opens in **mock mode** by default (`VITE_DATA_SOURCE=mock` in `.env`):
every list/create/edit/delete action runs against generated dummy data held
in memory + `localStorage`, so the whole UI is clickable and testable with
zero backend setup.

## Connecting to the real API

The FastAPI backend is expected at:

```
http://localhost:8000
```

To point the UI at it instead of mock data, edit `.env`:

```
VITE_DATA_SOURCE=live
VITE_API_BASE_URL=http://localhost:8000
```

Each entity's `src/api/<entity>Api.ts` calls the matching REST route
(`GET/POST/PUT/DELETE {route}` and `{route}/:id`) with standard JSON
request/response bodies.

## Project structure

```
src/
  api/         fetch wrappers for the live backend
  components/  shared UI kit (Button, Badge, Drawer, Toast, ...) + per-entity
               table & form components
  mock/        deterministic dummy data per entity
  pages/       one list/detail page per entity + a dashboard
  services/    mock-vs-live switch used by every page
  types/       TypeScript interfaces generated from the field spec
```
