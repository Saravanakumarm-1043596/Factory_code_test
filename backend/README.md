# acme-health-s-firewall-rule-sets-across-backend (backend)

A FastAPI + SQLAlchemy backend, generated by the **UISenz** LangGraph agent
from the same field spec used to generate the paired React frontend --
routes, types, and CRUD shape all line up with it exactly.

## Entities

- **NetworkSecurityGroup** -- `/api/networksecuritygroups`
- **Appliance** -- `/api/appliances`
- **FirewallRuleSet** -- `/api/firewallrulesets`
- **FirewallRule** -- `/api/firewallrules`
- **RuleIssue** -- `/api/ruleissues`
- **ChangeRequest** -- `/api/changerequests`
- **ProtectedSystem** -- `/api/protectedsystems`
- **AuditScan** -- `/api/auditscans`
- **ScanFinding** -- `/api/scanfindings`
- **ComplianceMapping** -- `/api/compliancemappings`

## Getting started

```bash
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

Uses a local SQLite file (`app.db`, created automatically) -- no external
database to provision. Each entity's table is seeded with deterministic
dummy rows on first startup (same generator/seed as the frontend's mock
data, so both sides show the same records).

## Linking to the frontend

The paired frontend defaults to `VITE_DATA_SOURCE=mock` (its own local
dummy data, no backend required). To point it at this backend instead, in
the frontend's `.env`:

```
VITE_DATA_SOURCE=live
VITE_API_BASE_URL=http://localhost:8000
```

CORS is pre-configured (see `.env`'s `CORS_ORIGINS`) to allow the frontend's
Vite dev server origin.

## Tests

```bash
pytest
```

Each entity has a create -> list -> get -> update -> delete -> 404 smoke
test against an isolated SQLite test database (`tests/conftest.py`).

## Project structure

```
app/
  database.py        SQLAlchemy engine/session (SQLite by default)
  models/             one SQLAlchemy model per entity
  schemas/             Pydantic request/response schemas per entity
  repositories/        raw CRUD per entity
  services/             thin service layer over the repository
  routes/               FastAPI router per entity
  seed.py               deterministic dummy data, inserted once per empty table
main.py                 FastAPI app assembly (CORS, routers, startup)
```
